# Atlas Intelligence

An **autonomous enterprise research and intelligence platform**. You submit a complex business question; a team of specialised agents plans the work,
searches and fetches real sources, extracts verbatim evidence, records claims, **verifies** them, classifies **conflicts**, **replans** when evidence is weak,
synthesises labelled inferences, and produces a cited, exportable report with a full audit trail. It is not a chatbot: nothing factual is generated by a model
without being grounded in a stored source.

## How it works

```
Question -> Research Manager (plan) -> specialised agents (parallel) -> ToolRegistry -> search/fetch/extract
        -> Sources -> Evidence (verbatim, grounded) -> Claims (born "proposed")
        -> Fact Checker (verification, conflicts, gaps) -> Manager replans (bounded) -> Analyst (inferences) -> Report
```
- **Agents** (`docs/AGENTS.md`): Research Manager, Market, Customer/Demand, Competitor, Pricing, Regulation, Risk, Fact Checker, Analyst. Each has explicit capabilities and an allow-list of tools (default deny).
- **Evidence integrity** (`docs/EVIDENCE.md`): SOURCE -> EVIDENCE -> CLAIM -> VERIFICATION are separate layers. An excerpt must appear verbatim in the stored source text; claims are never "verified" by their creator; verification rows are append-only; DB composite foreign keys stop cross-research references.
- **Verification**: deterministic rules first (integrity, quote grounding, numeric grounding, independent corroboration, contradictions, freshness); an LLM judge is optional and only refines stance. Outcomes: supported, partially_supported, contradicted, insufficient_evidence.
- **Conflicts**: classified before flagging. Different period/geography/definition/methodology/population = scope difference (explained), not a contradiction.
- **Replanning**: reasons `INSUFFICIENT_EVIDENCE`, `VERIFICATION_FAILED`, `LOW_SOURCE_QUALITY`, `CONFLICT_DETECTED`, `MISSING_DIMENSION`; hard cap `MAX_REPLANS`; visible in the timeline.
- **Reports**: every finding is a stored claim quoted verbatim with citations; claims without evidence are gaps; inferences are labelled INFERENCE/UNCERTAINTY and may not introduce numbers. Markdown/JSON/PDF export of an immutable version.
- **Security** (`docs/SECURITY.md`): httpOnly cookie sessions + CSRF, Redis-backed rate limits with safe fallback, SSRF protection on every redirect hop, RBAC, workspace/research isolation, secret redaction in logs.
- **Observability**: structured JSON logs with request/research/task/agent/tool-execution ids; per-call LLM usage; audit log.

## Modes
- **Production**: `LLM_API_KEY`, `WEB_SEARCH_PROVIDER=brave` + `WEB_SEARCH_API_KEY`. Missing credentials fail loudly; there is never a silent fallback to demo data.
- **Demo**: `DEMO_MODE=true`, `WEB_SEARCH_PROVIDER=demo`, `LLM_PROVIDER=demo`. Fictional pages on the reserved `.invalid` TLD; every record is `is_demo` and shown as MOCK/DEMO, including in reports.

## Known limitations
See `docs/UNVERIFIED.md` (what has not been run) and the limitation lists in `docs/SECURITY.md`, `docs/EVIDENCE.md`, `docs/TOOLS.md`. Notable: PDF export is Latin-1 only (Arabic text becomes `?`); no password reset/email verification/2FA; stateless sessions (no server-side revocation); no robots.txt handling, no JS rendering, no PDF source ingestion; unit conversion is not attempted when matching numbers.
